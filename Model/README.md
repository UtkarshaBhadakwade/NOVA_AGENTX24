# Models & Agent Frameworks

This directory houses the core multi-agent models and orchestration nodes that power NOVA Agent.

## Subdirectories
- **`Model_1_Supervisor/`**: Supervisor Agent dynamic planning, task decomposition, parallel dispatch, resource budgeting, and failure recovery model (`supervisor.py`).
- **`Model_2_Evaluator/`**: Evaluator Agent self-evaluation, analytical hypothesis verification, evidence conflict detection, and confidence scoring model (`evaluator.py`).
- **`Model_3_Synthesis/`**: Strategic Synthesis Agent grounded intelligence report generation model (`synthesis_agent.py`).
